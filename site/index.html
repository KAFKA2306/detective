文章の統計は、年代で本当に変わっている？

Zennの固定221件をprimary study、noteの固定36件を別cohortのreplicationとして同じ1,000文字の正規化条件で検証しました。媒体を混ぜてeffect sizeを合成せず別々に評価した結果、どちらからも安定したpublication-time signalは確認できていません。

2022→2026のbigram entropy平均差は +0.0907 bits（bootstrap 95% CI −0.3288〜0.4289）、trigramは +0.1600 bits（−0.1471〜0.4167）。detector confidence差は +0.0205（−0.0566〜0.1045）で、いずれも区間は0を含みます。2026年は4件、same-author NCDは8 pairsのため、endpoint比較は弱い証拠です。

EXTERNAL VALIDITY

2媒体を別々に検証しても、年代推定の根拠は得られない

Zennとnoteはsampling frameが異なるため数値をpoolしていません。それぞれの固定cohortを独立に評価した結果、validated publication-time signalは0件です。この結果から個別文章の年代やAI生成の有無を推定しません。

媒体別の数値、限界、protocol boundary、一次情報URLは external-validity evidence と GitHub evidence で確認できます。
